# Changelog

## 0.1.0 — 2026-10-13

First public release of Traceforge.

- Local CLI and nine-tool MCP interface.
- Immutable evidence snapshots with content fingerprints and source provenance.
- Babel-based JavaScript/TypeScript/Electron interface candidates and import maps.
- Package dependency inventory, recorded HAR metadata and lightweight binary inspection.
- Content and semantic version diffs with explicit partial-coverage limits.
- Responsive read-only dashboard and standalone offline HTML reports with history.
- Evidence-linked reconstruction briefs and JSON exports.
- Pinned REA 6.4.0 CLI access and lazy persistent MCP engine bridge.
- Core/CLI/MCP and real Chromium tests; Node 22/24 GitHub CI.

Native engine providers and automatic import of REA Evidence into Traceforge snapshots are outside this release's independently verified scope.
